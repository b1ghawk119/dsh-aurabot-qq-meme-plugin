# 1.2.1：自带黄仁勋模板

- 基础库新增“黄仁勋说”和“黄仁勋举牌”两个条目，举牌共用笑/哭两张底图。基础库 732 个，可选扩展仍为 273 个，全部启用为 1005 个。
- Windows 在扩展关闭时实际生成“说”、笑脸举牌、哭脸举牌；检查了实际输出，文字避开人物与手指，在用户指定区域内排版。共用渲染器优先按标点换行，不修改用户文字。
- 同一工作进程先生成模板再生成 732 项目录图，验证共用 WASM 实例、中文字体与目录入口。未增加运行依赖。
- 公共测试共 35 项通过，新增文本框边界、长文适配、标点换行、文本转义、默认文字、别名和笑哭参数检查。macOS/Linux 未测试。
- 素材出处见 assets/README.md。安装器随基础库复制素材，离线包默认包含它们。

# 1.2.0 验证记录

运行环境：Windows x64，AuraBot 1.2.1；macOS/Linux 保留平台与路径适配，未测试。

- Windows 公共测试 31 项通过：输入参数、头像与引用图片优先级、前缀、搜索分页、目录排版、扩展状态、错误隔离和 ICU 数据安装。
- 真实 panel.js 在 Windows Edge 中连接运行模块 API，点击卸载、再安装，模板数依次为 1003 → 730 → 1003。控件位于目录列数右侧，无 Python 等实现说明。
- 卸载后扩展模板从目录移除、Python 生成进程退出；扩展目录的 13,726 个文件/目录条目保留。模块重载后仍保持卸载状态，再安装复用本机资源。
- 只用“小强举牌”启动扩展生成进程并验证卸载；通过 AuraBot 模拟入口完成真实生成、捕获发送，不实际发群。未遍历模板，也未查看模板图片。
- 首次安装沿用已接入的固定版本资源/运行环境准备器；本次主要实测当前已有资源的挂载与卸载，未重新下载整库。
- 当前已部署版本保留全部可用模板，基础库 730 个，可选扩展 273 个。用户当前扩展恢复到已安装状态。

## 已包含的修复

- 引用图片优先于 QQ 自动附带的作者 @；头像和文字不足统一补齐。
- 搜索保留关键词翻页，并给出可复制的上下页指令。
- Windows Skia ICU 数据复用到正确位置；安装器与离线打包同步检查。
- 底层异常仅进入本机日志，聊天与面板只显示明确的使用提示或通用失败提示。安全测试使用虚构私有路径和令牌，覆盖制作、预览、查询、管理与初始化失败。

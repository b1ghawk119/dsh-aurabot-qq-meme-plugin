# 1.3.5：公共路径集中走查

- 文字解析：保留单段文案中的网址、日期、换行及空格；多段文案支持引号内斜杠、空段补齐；零文字模板忽略库中仅供预览的默认文案。带空格的参数值和快捷触发词中的名字统一处理。
- 消息入口：`/表情` 使用原始消息段，不把真正的 @ 当作文字，也不吞掉“开”等字开头的模板名；兼容 CQ 字符串中的 @、图片与引用。附图足够时不再依赖引用消息可读取。快捷预览携带对应选项。
- 故障恢复：生成进程连接失败时立即清理等待任务，下次请求可恢复；超时后继续队列并保留扩展开关；模块停止后不再挂载扩展、回写目录或启动进程。扩展安装加独立写入锁，残缺或旧版缓存标记可进入重试准备流程。
- 基础库与扩展库共用文字过长、图片不可读等安全提示，不回显输入内容或环境路径。面板在收藏减少后自动回到有效页，保存失败有提示，空搜索有明确状态。
- Windows 代表性生成只使用两个模板：基础库 `anya_suki` 验证无需文字但含默认文案的情况；扩展“小强举牌”验证文字生成。1005 个模板正常载入，未遍历渲染模板，未实际向 QQ 发送测试消息。Edge 用受控目录验证收藏翻页、保存失败及空搜索，生成图片和面板截图已检查。
- Windows 公共测试 65/65 通过，覆盖参数、消息、队列与停止恢复、扩展安装状态、隐私边界和安装打包。macOS/Linux 未做运行验收。
